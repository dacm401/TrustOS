# Reviewer Feedback Archive

Sanitized, non-personal records of private beta reviewer sessions.

## Rules

- Each session is one file: `session-NNN-<role-or-topic>.md`.
- Use the sanitized template from `session-001-template.md` (also available at
  `../REVIEWER_FEEDBACK_TEMPLATE.md`).
- **Do NOT** commit real reviewer personal data (names, emails, handles) unless
  the reviewer explicitly approves.
- **Do NOT** commit secrets, `.env`, `DATABASE_URL`, or API keys.
- Report environment as `live env supplied: yes/no` only — never the value.
